El propósito es que cada grupo conozca una tecnología relacionada con el curso y pueda explicar cómo se utiliza y en qué situaciones reales ha sido aplicada.

**Presentación(PPT)**
La PPT debe contener: 

* Qué es la tecnología o técnica   
* Para qué se utiliza  
* Cómo se relaciona con Python y Machine Learning  
* Principales características o posibilidades  
* Tecnologías, librerías o herramientas relacionadas  
* Aplicaciones que se hayan desarrollado utilizando esta tecnología  
* Casos de éxito  
* Proyectos desarrollados por empresas  
* Aplicaciones utilizadas en organizaciones
