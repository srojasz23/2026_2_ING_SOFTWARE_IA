# TRABAJO FINAL DEL CURSO
## FUNDAMENTOS Y ALGORITMIA PARA INTELIGENCIA ARTIFICIAL

### Análisis, desarrollo y evaluación de modelos de Machine Learning

---

## 1. TEMA

**Desarrollo y evaluación de algoritmos de Machine Learning aplicados a problemas reales mediante datasets de Kaggle.**

---

## 2. OBJETIVO

Al finalizar el trabajo final, el estudiante será capaz de analizar un problema de clasificación, preparar un conjunto de datos, desarrollar modelos de Machine Learning y evaluar su desempeño utilizando fundamentos de:

- K-Nearest Neighbors (KNN).
- Probabilidad y Naive Bayes.
- Support Vector Machines (SVM).
- Optimización de modelos.
- Evaluación y métricas de clasificación.

Deberan de fundamentar sus decisiones técnicas, interpretar los resultados obtenidos y determinar cuál de los modelos desarrollados resulta más adecuado para el problema planteado.

---

## 3. ORGANIZACIÓN DEL TRABAJO

El trabajo será desarrollado en **4 grupos de 2 estudiantes**.

Cada grupo trabajará con un **dataset diferente de Kaggle**.

| Grupo | Dataset asignado | Problema |
|---|---|---|
| **Grupo 1** | Breast Cancer Wisconsin Diagnostic | Clasificación |
| **Grupo 2** | Pima Indians Diabetes | Clasificación |
| **Grupo 3** | Loan Approval Prediction | Clasificación |
| **Grupo 4** | Red Wine Quality | Clasificación |

# 4. DATASETS ASIGNADOS

## GRUPO 1 - Breast Cancer Wisconsin Diagnostic

**Dataset:** Breast Cancer Wisconsin Diagnostic - Kaggle

El dataset contiene características calculadas a partir de imágenes digitalizadas de aspiraciones con aguja fina de masas mamarias.

### Los estudiantes deben investigar

- Contexto del problema.
- Significado de las variables.
- Variable objetivo.
- Características del dataset.
- Distribución de las clases.
- Relación entre las variables y la variable objetivo.
- Importancia de la clasificación en este contexto.
- Limitaciones del dataset.

## GRUPO 2 - Pima Indians Diabetes

**Dataset:** Pima Indians Diabetes – Kaggle

El dataset contiene variables relacionadas con mediciones diagnósticas y una variable objetivo utilizada para determinar la presencia o ausencia de diabetes.

### Los estudiantes deben investigar

- Contexto del problema.
- Significado de las variables.
- Variable objetivo.
- Características estadísticas del dataset.
- Distribución de las clases.
- Posibles problemas de calidad de datos.
- Relación entre las variables predictoras y el resultado.
- Importancia de seleccionar métricas adecuadas para este problema.

## GRUPO 3 - Loan Approval Prediction

**Dataset:** Loan Approval Prediction – Kaggle

El dataset contiene información de solicitantes de préstamos y una variable objetivo que indica si el préstamo fue aprobado o no.

### Los estudiantes deben investigar

- Contexto del problema.
- Características de los solicitantes.
- Variables predictoras.
- Variable objetivo.
- Variables categóricas y numéricas.
- Calidad de los datos.
- Distribución de las clases.
- Posibles factores relacionados con la aprobación de un préstamo.
- Riesgos de utilizar un modelo de clasificación en este contexto.

---

## GRUPO 4 - Red Wine Quality

**Dataset:** Red Wine Quality – Kaggle

El dataset contiene características fisicoquímicas del vino y una variable relacionada con su calidad.

### Los estudiantes deben investigar

- Contexto del problema.
- Significado de las variables fisicoquímicas.
- Variable objetivo.
- Distribución de las categorías.
- Comportamiento de las variables.
- Posible desbalance de clases.
- Relación entre características fisicoquímicas y calidad.
- Criterio utilizado para plantear el problema de clasificación.

# 6. DESARROLLO DEL TRABAJO
Cada grupo deberá desarrollar una propuesta de solución para el problema asignado.
El trabajo deberá contemplar, como mínimo:

## A. Comprensión del problema

- Descripción del problema.
- Contexto.
- Objetivo del modelo.
- Variable objetivo.
- Variables predictoras.

## B. Análisis del dataset

- Características generales.
- Tipos de variables.
- Distribución de los datos.
- Análisis exploratorio.
- Visualizaciones relevantes.
- Identificación de problemas en los datos.

## C. Preparación de los datos

El grupo deberá determinar las estrategias necesarias para preparar los datos antes del modelamiento.

## D. Desarrollo de modelos

Se deberán utilizar los conocimientos estudiados durante el curso:

- KNN.
- Naive Bayes.
- SVM.

No necesariamente todos los algoritmos tendrán el mismo comportamiento en cada dataset.

> **La selección y justificación será responsabilidad del grupo.**

## E. Optimización

Los estudiantes deberán analizar si la configuración inicial de los modelos puede ser mejorada.

Deberán justificar:

- Qué parámetros analizaron.
- Qué estrategia utilizaron.
- Qué resultados obtuvieron.
- Qué configuración seleccionaron finalmente.

## F. Evaluación

Los modelos deberán compararse utilizando métricas adecuadas.

Los estudiantes deberán interpretar los resultados y no limitarse a presentar tablas de valores.

## G. Conclusiones

Las conclusiones deberán responder:

- ¿Qué aprendieron del dataset?
- ¿Qué modelo funcionó mejor?
- ¿Por qué?
- ¿Qué métrica fue más relevante?
- ¿Qué limitaciones encontraron?
- ¿Qué podría mejorarse?
